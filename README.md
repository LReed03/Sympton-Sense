# Symptom Sense

Symptom Sense is a full-stack app that predicts symptom urgency levels using machine learning. It is not meant to replace professional medical opinions. Only for education.

## Features
- Symptom input form
- ML-based urgency prediction
- ASP.NET Core backend API
- PostgreSQL database
- User history storage

## Tech Stack
- React Native + Expo
- ASP.NET Core (C#)
- PostgreSQL + Entity Framework
- Python + Scikit-learn

Built as a learning project for full-stack and ML integration.  
Educational use only — not medical advice.
